# 🚀 C Day 11 — Part C

## String Utility Analyzer

A menu-driven C program that performs different operations on strings using
standard string library functions and custom logic.

---

## 🎯 Objective

The main objective of this task is to practice:

- String library functions
- Character searching
- Substring searching
- String comparison
- String concatenation
- String case conversion
- String reversal
- Pointers returned by string functions
- Menu-driven programming

---

## 🛠️ Technologies Used

- Language: C
- Header Files:
  - `stdio.h`
  - `string.h`
  - `ctype.h`

---

## 📋 Features

The program provides the following operations:

1. Find String Length
2. Copy String
3. Compare Two Strings
4. Concatenate Two Strings
5. Find Character
6. Find Substring
7. Count Substring Occurrences
8. Convert String to Uppercase
9. Convert String to Lowercase
10. Reverse String
11. Exit

---

## 📚 Functions Practiced

| Function    | Purpose                                   |
| ----------- | ----------------------------------------- |
| `strlen()`  | Finds the length of a string              |
| `strcpy()`  | Copies one string into another            |
| `strncpy()` | Copies a specified number of characters   |
| `strcmp()`  | Compares two strings                      |
| `strncmp()` | Compares a specified number of characters |
| `strcat()`  | Joins two strings                         |
| `strncat()` | Joins a specified number of characters    |
| `strchr()`  | Finds the first occurrence of a character |
| `strstr()`  | Finds the first occurrence of a substring |
| `toupper()` | Converts a character to uppercase         |
| `tolower()` | Converts a character to lowercase         |
