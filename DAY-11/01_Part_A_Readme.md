# C String Library — Part 1

Practice with commonly used functions from `<string.h>`.

## Functions

- `strlen()` — Find string length
- `strcpy()` — Copy a string
- `strncpy()` — Copy limited characters
- `strcat()` — Join strings
- `strncat()` — Join limited characters
- `strcmp()` — Compare strings
- `strncmp()` — Compare limited characters

## Concepts Practiced

- String length
- String copying
- String concatenation
- String comparison
- `source` and `destination`
- Limited string operations using `n`
- `strlen()` vs `sizeof()`

## Header File

```c
#include <string.h>
```
